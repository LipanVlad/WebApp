# Web Application API

A CRUD REST API for a Reddit-style forum featuring JWT authentication, communities, posts, and comment threads. 

## Tech Stack
* Java 17 & Spring Boot 3
* PostgreSQL & Spring Data JPA (Hibernate)
* Spring Security (JWT)
* Maven

## Features
* **Auth:** Stateless JWT login and registration
* **Communities:** Create and browse isolated communities
* **Posts:** Segmented data fetching with minimal loading time
* **Comments:** Infinitely nested thread architecture
